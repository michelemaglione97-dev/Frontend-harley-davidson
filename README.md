# Frontend Harley-Davidson

Progetto web frontend sviluppato per la presentazione di modelli di moto e accessori Harley-Davidson, con particolare attenzione alla cura del design responsive e all'interattività utente tramite JavaScript.

## 🛠️ Tecnologie e Strumenti Utilizzati
- **HTML5**: Struttura semantica delle pagine.
- **CSS3**: Stili personalizzati, layout e design responsive (cartella `css/`).
- **JavaScript**: Logica di interazione e gestione dei moduli (cartella `js/`).
- **Bootstrap / Framework CSS** (se utilizzato)
- **Git & GitHub Pages**: Controllo versione e hosting del sito statico.

## 📄 Struttura delle Pagine
Il sito è composto principalmente da due pagine chiave:
1. **`index.html`**: La home page del progetto, che introduce il brand, i modelli in vetrina e la navigazione principale verso le sezioni dedicate agli accessori e ai dettagli.
2. **`registrati.html`**: La pagina dedicata alla registrazione dell'utente, contenente un form strutturato con vari campi di input e validazione dei dati lato client tramite JavaScript.

## 🚀 Come Visualizzare il Progetto
Puoi testare il progetto in due modi:
- **Online**: Visitando il sito pubblicato tramite **GitHub Pages** (trovi il link diretto nella sezione *About* a destra della pagina del repository).
- **In Locale**: 
  1. Clona o scarica il repository sul tuo computer.
  2. Apri la cartella del progetto.
  3. Fai doppio click sul file `index.html` (o aprilo con il tuo browser preferito o con un editor come VS Code / Eclipse) per navigare tra le pagine.
